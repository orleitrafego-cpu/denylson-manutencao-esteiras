# D&J Manutenção de Esteiras

Landing page para anúncios do Google. Leva o visitante a agendar a visita técnica pelo WhatsApp (11) 93053-5990.

## Estrutura

- `index.html`: a página inteira (HTML, CSS e JavaScript no mesmo arquivo)
- `logos/`: logo da D&J, ícone da aba, logos dos clientes e `logos/marcas/` com as marcas de esteira
- `fotos/`: foto do técnico em duas versões (`dj-manutencao-foto-hd.webp` para computador, `dj-manutencao-foto.webp` para celular)

## Como publicar

É um site estático. Basta servir a pasta inteira (por exemplo, pelo GitHub Pages ou qualquer hospedagem de arquivos), mantendo `index.html`, `logos/` e `fotos/` juntos.
